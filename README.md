## Selected projects

### [EvoODE](https://github.com/dajoedic/EvoODE)

A Julia framework for discovering interpretable ODE systems from time-series data.

The project focuses on incremental model growth, reproducible experiments and the question of how much model complexity is actually necessary.

### [Evergreen](https://github.com/dajoedic/evergreen)

A local personal AI assistant with persistent memory, structured data and multiple domain-specific agents.

Built with Next.js, TypeScript, SQLite and LLM APIs.

### [Handball Video Cutter](https://github.com/dajoedic/videocutter)

A small keyboard-driven tool for cutting and categorizing handball video scenes.

Built because manually cutting match footage is annoying.
